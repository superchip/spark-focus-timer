Privacy & Data Use

Spark is designed to respect your time and your privacy. We do not collect, transmit, sell, or monetize personal data. All state and preference storage happens locally in Chrome's extension storage areas.

What We Store

  • Timer state & statistics (focus sessions completed, total focus minutes, streak). Stored locally via chrome.storage.local. Resettable at any time from the Options page.
  • Preferences (durations, content type toggles, notification preference). Stored via chrome.storage.sync. See the Chrome Sync section below for details.
  • Debug logs — only created and stored locally when you explicitly enable Debug Mode in Settings. Never transmitted. Deletable via the debug console or Options page.

What We Do NOT Collect

  • No browsing history
  • No personally identifiable information
  • No analytics, telemetry, tracking pixels, or fingerprinting
  • No third-party advertising libraries

Network Requests

During break periods, the extension fetches content from the following public APIs (only for types you have enabled):

  • Facts: https://uselessfacts.jsph.pl/ (primary) and https://catfact.ninja/ (fallback)
  • Quotes: https://api.quotegarden.io/ (primary) and https://api.quotable.io/ (fallback)

These requests are fully anonymous — no user data, identifiers, or browsing history are included. Responses are rendered locally; nothing is forwarded to any third party. If all API endpoints are unavailable, no external request is made.

Chrome Sync & Google Servers

Preferences (timer durations, toggle states, notification setting) are stored in chrome.storage.sync. When your Chrome browser has account sync enabled, these preferences are synced across your signed-in Google account — this means preference data travels through Google's servers. No personally identifiable information is included in these preferences. You can prevent this by disabling Chrome Sync in your browser settings (chrome://settings/syncSetup); the extension works fully without sync.

Debug Mode

This extension includes an optional Debug Mode (disabled by default). When enabled via the Settings panel, it provides a console for simulating sessions, inspecting local storage, and exporting logs. Debug logs are stored only on your device and can be cleared at any time. This feature is intended for testing; normal users never need to enable it.

Permissions Justification

  • storage: save your preferences, timer state, and daily statistics.
  • alarms: drive focus and break timers reliably in the background, even when the popup is closed.
  • notifications: inform you when a session ends with quick-action buttons (can be disabled in Settings).
  • host_permissions: limited to the four public API domains used for break content (facts and quotes).

Incognito Mode

Spark does not run in incognito windows.

Data Deletion

You can delete all stored data at any time from the Options page using the Delete All Extension Data button. Uninstalling the extension also removes all stored data from your device.
